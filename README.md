# Integrazione-di-Sentiment-Analysis-in-NL-based-virtual-humans-per-Vesna-Unity
Integrazione di Vesna-Unity per identificazione del "mood" con cui un utente in un ambiente di VR sta parlando con un virtual humans, così che il VH possa reagire in base al sentimento espresso dall'utente mostrando modifche alle espressioni facciali e al tono nella risposta ​
